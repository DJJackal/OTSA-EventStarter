# Changelog

All notable changes to OTSA-EventStarter will be documented in this file.

## [1.2.0] - 2026-09-05

### Added

- Public GitHub release.
- Optional event names for server-wide announcements.
- ACE-protected `/eventstart` and `/eventfinish` commands.
- F5 event joining through FiveM key mapping.
- Server-side saving of participant coordinates and heading.
- Automatic participant restoration when an event is finished.
- Automatic restoration if the event starter disconnects.
- Single-session protection to prevent overlapping events.
- Event-name sanitisation and configurable maximum length.
